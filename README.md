# 🌿 Plant Disease Detection Using EfficientNet

An AI-powered plant disease detection system that leverages **EfficientNet** and Deep Learning to identify plant diseases from leaf images. This project helps farmers, researchers, and agricultural professionals detect diseases early, enabling timely treatment and improved crop health.

---

## 📌 Overview

Plant diseases significantly impact agricultural productivity and food security. This project uses a pre-trained **EfficientNet** convolutional neural network to classify plant leaf images into healthy or diseased categories with high accuracy.

The model is trained using transfer learning, allowing efficient feature extraction while reducing training time and improving performance.

---

## 🚀 Features

- 🌱 Automatic plant disease detection
- 🧠 EfficientNet-based deep learning model
- 📷 Image classification from uploaded leaf images
- ⚡ High accuracy using transfer learning
- 📊 Model evaluation with accuracy and loss metrics
- 🔍 Supports multiple plant disease classes
- 💻 Easy-to-use prediction interface

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/Plant-Disease-Detection-Using-EfficientNet.git

cd Plant-Disease-Detection-Using-EfficientNet
```

### Create a virtual environment

```bash
python -m venv venv
```

Activate it:

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```
